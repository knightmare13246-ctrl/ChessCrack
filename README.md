# ChessCrack ♟️

**ChessCrack** is a high-performance chess analysis and study application built with Flutter, inspired by Nibbler. It features native, on-device evaluation using **Stockfish** and **Leela Chess Zero (Lc0)** neural networks.

---

## Features

- **Dual Native Engines**: Real-time evaluation powered by Stockfish and Lc0.
- **Move Exploration & Visual Tree**: Step through games, examine variations, and analyze branching moves.
- **Board & Piece Customization**: Rich themes and multiple authentic piece sets.
- **Audio & Haptic Feedback**: Dynamic move sounds and board interactions.
- **100% Free & Open Source**: No telemetry, no ads, no trackers.
