ChessCrack is a dedicated offline chess analysis workbench and neural network exploration utility for Android, inspired by desktop tools like Nibbler and DroidFish.

NOTE: ChessCrack is an analytical utility and study workbench for serious chess players and researchers, not a casual game. It does not feature player matchmaking or gamified elements.

Modular Architecture (Zero-Binary Base APK):
To maintain a lightweight footprint (< 20 MB base package) that respects user storage and mobile data limits, ChessCrack contains NO bundled engine binaries or neural networks. Through the built-in Engine & Network Manager, users download verified official releases directly to their device:
- Stockfish: Official native releases from the Stockfish project.
- Leela Chess Zero (Lc0): Official Android native releases.
- Maia Human Sparring Networks: Official Maia weights (1100 to 2200 Elo at Nodes = 1) trained to predict human moves.

Features:
- Dual Engine Architecture: Alpha-beta search (Stockfish) and Monte Carlo tree search (Lc0).
- Human Sparring Exploration: Evaluate positions against Maia neural networks for realistic human-like move suggestions.
- Interactive Move Tree: Explore branching variations, sidelines, and game annotations with full navigation.
- Dynamic Visual PV: Real-time candidate move arrows overlaid on the board with customizable styles.
- PGN & FEN Management: Quick import/export, paste PGN, and copy FEN.
- Diagnostics & Metrics: Live nodes per second (NPS), search depth, selective depth, and hash table metrics.
- Complete Privacy: 100% offline analysis after engine download. Zero tracking, zero telemetry, zero advertisements.
- Fully Open Source: Free and open-source software licensed under GNU General Public License v3.0 (GPL-3.0-or-later).
